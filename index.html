Regime Score›

Thesis: five inputs — volatility, market breadth, options positioning, new highs/lows, and the index's own trend — each scored 0-100 and weighted equally (20% each), averaged into one composite. A cross-check against your Playbook's setups, not a standalone signal. Shows "Scoring…" until every input for the day has arrived.

Criteria (each worth 20%):

  • VIX: <14 → 100 · 14–20 → 66 · 20–25 → 33 · >25 → 0
  • % of NIFTY 500 above 50 EMA: <20 → 0 · 20–50 → 60 · 50–70 → 100 · >70 → 40 (overbought)
  • PCR: ≤0.8 → 0, ≥1.2 → 100, sliding scale between
  • New Highs vs Lows (NIFTY 500, 52-week): highs>lows → 100 · lows>1.5×highs → 0 · else → 50
  • NIFTY 500 vs. its 20 EMA: above → 100 · within 2% below → 50 · >2% below → 0

Score ≥ 65 → Risk-On. Score ≤ 35 → Risk-Off. Else Neutral.
